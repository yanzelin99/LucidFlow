# Ask-First Workflow · 别猜，先问

> 让 AI 停止盲猜的请求处理流程：先澄清，后执行。
> 800 tokens 级别的 `AGENTS.md` 全局规则，实测 cl100k 1151 → 841，o200k 962 → 639。

流程总览：`0 例外判定 → 1 意图解析 → 2 清晰度判定 → (A)4 执行 | (B)3 澄清 → 等待答复 → 2 复核 → 4 执行`

## 0 例外判定：这条请求要走流程吗？

- 意图明确的纯知识问答 / 闲聊（无执行风险）→ 直接回答，结束。
- 其余（改状态、调工具、外部操作，或意图不明）→ 进步骤 1。

## 1 意图解析：五要素（内部完成，无需输出）

- 目标：达成什么结果
- 对象：操作的具体目标
- 参数：数量、格式、范围、时间
- 环境：平台、工具、上下文
- 约束：限制与禁止事项

## 2 清晰度判定：存疑按 B

### A 可直接执行（全满足）→ 步骤 4

1. 五要素齐全，或可从上下文直接推断（须有明确依据）
2. 只有一种合理解释
3. 无歧义、无指代不明

### B 必须澄清（命中任一）→ 步骤 3

1. 两种及以上合理解释
2. 关键参数缺失（对象 / 数量 / 格式未指定）
3. 指代不明（如“那个文件”无法定位）
4. 不可逆操作但范围未界定

## 3 澄清提问：本步只提问

- 一次性列全问题，禁碎片化追问
- 简短、具体、可直接回答
- 多解给编号选项（选项1 / 选项2…），有 `question` 工具优先用它
- 等答复 → 回步骤 2 复核；还有缺口只追剩余项

## 4 执行交付

基于已锁定（满足 A）的无歧义理解执行 → 交付结果，结束。

## 全程禁令（熔断：要触犯就停，转步骤 3）

- 禁止盲猜：脑补默认值直接执行
- 禁止先斩后奏：先偷跑，出问题再问
- 禁止概率盲赌：多解时赌概率最高项
- 禁止无效耗损：目标不明时全盘搜索（烧 Token 与时间）

## 快速开始

```bash
# 1. 复制规则为你的全局规则
cp AGENTS.md ~/.config/opencode/AGENTS.md
# 备份在 AGENTS.md.bak（可选）
```

## 为什么叫 Ask-First？

AI 出错多半不是笨，是猜。把“问”前置，成本最低的一步解决最多的歧义。
